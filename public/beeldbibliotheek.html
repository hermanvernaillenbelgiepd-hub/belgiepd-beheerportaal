Afbeelding toevoegen of vervangen

Voor een afbeelding in de personeelskaart kies je bij voorkeur Specialisatiebadge. Een upload met bijvoorbeeld code semi_ano wordt voortaan automatisch gevonden bij SEMI ANONIEM. Kies dezelfde code om een bestaande patch te vervangen; afbeeldingsuploads wijzigen nooit specialisatierechten.
